# Security

Dynamic Island runs on your computer with access to things that matter:
notifications, your mail and WhatsApp (when you connect them), your files when
you use Documents or drag actions, and Claude Code's permission prompts. Reports
of anything that could expose or misuse them are very welcome.

## Reporting a vulnerability

Please report it privately with GitHub's
[Report a vulnerability](https://github.com/shashanksharma280201/dynamic-island-linux/security/advisories/new)
form, not in a public issue. Include what's affected, how to reproduce it and
what someone could do with it. You'll get an answer within a week, and credit
in the release notes when it's fixed (unless you'd rather not).

## Supported versions

Fixes go into the latest release. Update with the one-line install command or
the newest download from [Releases](https://github.com/shashanksharma280201/dynamic-island-linux/releases).
